# Sistema de registro y ventas para tienda tecnológica

## Descripción
Este proyecto implementa una aplicación web simple con arquitectura cliente-servidor, backend en Express, API RESTful y una interfaz HTML/CSS/JS responsive para gestionar productos y ventas.

## Requisitos
- Node.js 18+
- npm

## Instalación
```bash
npm install
```

## Ejecución
```bash
npm start
```

## Login de prueba

## Endpoints principales
- `POST /api/login`
- `GET /api/products`
- `POST /api/products`
- `PUT /api/products/:id`
- `DELETE /api/products/:id`
- `POST /api/sales`
- `GET /api/sales`
